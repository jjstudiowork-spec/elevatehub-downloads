# Stream Deck Plugin Privacy

The ElevateHub Stream Deck plugin does not collect, sell, transmit, or retain
personal information. It communicates with ElevateHub only through a local
WebSocket connection on the same computer at `127.0.0.1:47825`.

Stream Deck button assignments are stored locally by the Stream Deck software
and ElevateHub. The plugin does not use analytics, advertising identifiers, or
third-party tracking services.

Questions can be submitted through the
[ElevateHub support tracker](https://github.com/jjstudiowork-spec/elevatehub-downloads/issues).
